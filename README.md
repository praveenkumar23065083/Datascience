## 1. YouTube Data Analysis & NLP

**Domain:** Natural Language Processing | Sentiment Analysis | Statistical Analysis

This project explores YouTube trending video data and user comments to understand audience engagement, sentiment, and patterns in online content.

### Key Components

**A. NLP-Based Comment Analysis**
- Processed approximately 7,000 YouTube comments.
- Applied transformer-based NLP models using Hugging Face.
- Used RoBERTa for sentiment classification.
- Explored audience opinions and patterns in user-generated content.

**B. Sentiment Analysis**
- Classified user comments into sentiment categories.
- Explored the distribution of positive and negative audience reactions.
- Investigated how audience sentiment reflects engagement with online content.

**C. Statistical Analysis**
- Performed statistical analysis on YouTube trending data.
- Applied hypothesis testing, t-tests, and ANOVA.
- Investigated relationships and differences between relevant dataset variables.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn, NLP, Hugging Face Transformers, RoBERTa, Statistical Testing.

## 3. Marketing A/B Testing

**Domain:** Statistical Analysis | Experimentation | Marketing Analytics

An A/B testing project designed to compare the effectiveness of two digital advertising platforms: Facebook Ads and Google AdWords.

The objective was to determine which platform generated better conversion performance using statistical and correlation-based analysis.

### Key Components
- Analysed 365 days of advertising campaign data.
- Compared daily conversions across both platforms.
- Applied Welch's independent two-sample t-test.
- Evaluated statistical significance and correlation.
- Used regression analysis to investigate advertising performance.

### Key Findings
- Facebook Ads averaged approximately 11.74 conversions per day.
- Google AdWords averaged approximately 5.98 conversions per day.
- Welch's t-test indicated a statistically significant difference (p < 0.001).
- Facebook showed a stronger correlation (r = 0.87) compared with Google AdWords (r = 0.45).
- The regression analysis achieved an R² of approximately 76%.

**Technologies:** Python, Pandas, NumPy, SciPy, Matplotlib, Seaborn, Statistical Hypothesis Testing.

## 4. Customer Segmentation Using RFM Analysis & K-Means

**Domain:** Unsupervised Machine Learning | Customer Analytics

A customer segmentation project involving more than one million transaction records to identify distinct customer groups based on purchasing behaviour and financial characteristics.

The objective was to transform raw transaction data into meaningful customer segments that could support business decision-making.

### Key Components
- Processed and analysed over one million transaction records.
- Engineered customer-level features using Recency, Frequency, and Monetary (RFM) analysis.
- Incorporated additional features such as account balance, age, and average transaction value.
- Applied Yeo-Johnson transformation and feature scaling.
- Evaluated K-Means clustering for different cluster counts (K = 2–10).
- Compared clustering solutions using silhouette scores.

### Key Findings
- Identified three meaningful customer segments: Low, Regular, and High.
- Segmented more than 143,000 customers.
- Evaluated clustering quality using silhouette scores and business interpretability.

**Technologies:** Python, Pandas, NumPy, Scikit-learn, K-Means, Feature Engineering, Matplotlib, Seaborn.
